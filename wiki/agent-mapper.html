Mapper Ag-3 Real

Assigns each verified document to a precise cell of the 16×13×48 matrix — theme, genre and month — using a Gemma LLM, finer-grained than the Archivero's mission-level counting.

Entry point: pipeline/mapper/__init__.py → main() · CLI: mapper run / status

Multi-category classification

The LLM returns 1–3 ranked categories (primary first) plus a month and confidence. parse_llm_response() validates the JSON (accepts both the new category_ids array and the legacy single category_id), dedupes, and enforces 1–3 distinct ids in 1–16. The primary id is stored in mapped_category_id (used by the coverage matrix); the full ranked list in mapped_categories (JSON).

Genre classification

The same LLM call also returns one genre_id (1–13, registry in lib/genres.py) — the document's form, not its topic (a news article about a speech is Prensa informativa, not Discurso). parse_genre_response() validates it; when missing or invalid the deterministic fallback genre_from_source() guesses from title keywords first ("decreto" → Documento oficial, "telegram" → Cable), then a connector prior (openalex/crossref/semantic_scholar → Académico, frus → Cable, chronicling_america → Prensa informativa, marxists → Discurso). If neither applies, mapped_genre_id stays NULL and the document counts under genre 0 (unclassified) in the matrix.

Reading & date-extraction rules (in the prompt)

  • What it IS, not what it MENTIONS: a speech on coup day defending democracy is primarily Política Nacional (1), not Política Militar (13).
  • Writing date, not event date: a memo written in March about action planned for June maps to month 03. For a span, take the end month. Undatable → 1971-06 fallback.

Out-of-scope tagging

If the document is outside Oct 1969–Sep 1973 or the LLM signals irrelevance (confidence 0.0), it is tagged doc_tag='context' and stamped (not retried) rather than treated as a parse failure.

Run modes

ModeBehaviour
defaultOne batch of unmapped verified docs.
--allAll verified docs (mapped + unmapped), self-terminating loop via a session timestamp.
--remapRe-classify already-mapped docs only (mutually exclusive with --all).
--no-llmFallback: category/month from the parent mission, genre from genre_from_source() (no Ollama).

After each batch, _refresh_coverage() recomputes the shared 3D coverage table (lib/coverage.py) from per-(theme, genre, month) document counts; NULL genres aggregate under genre 0. A doc the LLM keeps failing is stamped (_stamp_skipped) so loops terminate.

Admin page

The Mapper has its own dashboard page at /mapper (endpoint /api/agents/mapper): mapped / pending / context counts, the share of mapped docs with a genre, genre and category distribution bars, and the most recent mappings. See Admin.

Common invocations

make mapper            # run --batch 50
make mapper-all        # run --all --batch 100
make remap-all         # run --remap --batch 100
uv run mapper status   # mapped / context / pending counts
