Cast Director Real

Step 8 of the canonical pipeline. Reads documents and the hard data the Cast Manager has assembled, and extracts the complex relational layer around each character.

What it does

Where the Cast Manager records facts (who appears, when, in what document), the Cast Director extracts the harder, inferential information:

  • Affective relations — friendships, rivalries, conflicts.
  • Familial relations — family ties.
  • Political affiliations — parties, factions, ideological alignment.
  • Professional / institutional links — colleagues, superiors, subordinates.
  • Enemies and adversaries.

Place in the flow

Runs after the Cast Manager: needs both the documents and the Cast Manager's character database / timelines as input. Its output is the relational graph that future runtime agents (NPC dialogue, scenarios) will draw on.

Implementation

Lives in pipeline/cast_director/__init__.py (class CastDirector, pure functions, a main() CLI). Persists to the character_relations table.

DecisionResolved as
SchemaA directed character_relations table — (source_character_id, target_character_id, kind, description, confidence, mention_count, provenance), UNIQUE(source, target, kind) — plus a relations_extracted_at stamp on documents (self-terminating, like the Cast Manager).
LLM strategyPer document, mirroring the Cast Manager: each verified, mapped doc is read once (Gemma, --no-llm = stamp-only no-op) and the relations it states are extracted, grounded in the people the Cast Manager already linked to that document.
Relation kindsCanonical set: familia, aliado, colega, rival, enemigo, afiliacion (symmetric); superior, mentor (directed); contraparte, otro. A bilingual map normalises surface kinds; inverse kinds (subordinate, student) flip into their directed counterpart. Symmetric pairs are stored ordered so A–B and B–A collapse to one row.
Endpoint resolutionBoth people must already be in the cast — names are resolved to character_id with the Cast Manager's coreference (resolve_character_key); a relation whose endpoint is unknown is skipped (counted as unresolved), and self-relations are dropped.
Political refinement (backlog #3)When both endpoints have a compass position, a claimed afiliacion between ideologically distant figures is corrected to contraparte on upsert (Kissinger↔Allende are not "afiliados"). The prompt also forbids "political" for opponents. Pure logic in lib/politics.py (refine_relation_kind).
Provenance & confidenceEvery relation carries the provenance list of doc_ids that justify it. Conflict resolution = accumulate evidence: re-seeing a relation appends the doc and raises confidence = min(1, docs/3) rather than overwriting; the richest description is kept.

CLI

uv run cast-director run [--batch 50] [--all] [--no-llm]
uv run cast-director status

Runs after the Cast Manager in every pipeline target. Records a cast_director stage against the active run_id.
