Commands

CLI entry points and every Makefile target. All pipeline agents are CLI tools; only Gatekeeper and Admin are long-running.

Setup & quality

uv sync                  # install all deps (including dev group)
uv run pytest -v         # full test suite (offline)
uv run pytest tests/test_X.py::fn   # single test
uv run ruff check .      # lint
uv run ruff format .     # format

CLI entry points (pyproject.toml [project.scripts])

CommandModuleRole
gatekeeperresearch_engine.gatekeeper.app:mainHTTP proxy on :8001 (keep running).
adminadmin.app:mainDashboard on :8080 (keep running).
propositorresearch_engine.propositor:mainGap detection + entity (character-research) mission generation.
archiveropipeline.archivero:mainFetch documents; run/status/export.
verificatorpipeline.verificator:mainScore/gate docs; run/status/clean.
mapperpipeline.mapper:mainMap docs to matrix cells; run/status.
cast-managerpipeline.cast_manager:mainExtract people from verified+mapped docs; run (--batch/--all/--no-llm)/merge (unify duplicate characters; also runs after every cycle)/enrich (Wikidata + Wikipedia links)/politics (political compass)/clean (remove implausible characters; dry-run unless --apply)/status.
cast-directorpipeline.cast_director:mainExtract character relations from verified+mapped docs; run (--batch/--all/--no-llm)/status.
doc-curatorpipeline.doc_curator:mainAssign utility flags to verified+mapped docs (Ag-9); run (--batch/--all/--re-curate/--no-llm)/status/clear (dry-run unless --apply).
pipeline-runlib.run_tracker:mainBracket a full run: start/finish (reads $CYBERSYN_RUN_ID).

Run tracking: the pipeline/drain Makefile targets mint one CYBERSYN_RUN_ID and export it so every agent stamps its stage timing + counts against it (Admin Performance/Results). Setting the env var is optional for standalone agent runs — when unset, stage recording is skipped. See Data Model → run tracking.

Pipeline (one-shot agents)

TargetRuns
make propositorpropositor run --limit 100 — generate 100 missions.
make propositor-statusShow mission-queue state.
make archiveroarchivero run --batch 50 --missions 200.
make archivero-statusDocument fetch stats.
make archivero-exportExport documents to data/documents.json.
make verificatorverificator run --batch 200.
make verificator-statusVerification stats.
make verify-queueLoop verificator until the queue is drained.
make cleanerverificator clean — delete rejected docs.
make cleaner-dry-runPreview rejections (no delete).
make mappermapper run --batch 50.
make mapper-statusMapping stats.
make mapper-allmapper run --all --batch 100 — (re)map all verified docs.
make remap-allmapper run --remap --batch 100 — re-classify already-mapped docs.
make cleaner-mapperClean then map in one step.
make cast-managercast-manager run --batch 50 — extract people from verified+mapped docs.
make cast-manager-statusCast stats (characters, mentions, facts, pending).
make cast-manager-allcast-manager run --all --batch 100 — mine all eligible docs.
make cast-reminecast-manager run --re-extract --batch 100 — re-mine already-processed docs (applies the improved extraction). Uses the LLM path; don't add --no-llm on real data.
make cast-enrichcast-manager enrich --limit 200 — link characters to Wikidata + Wikipedia. Requires make gatekeeper running.
make cast-analyzecast-manager analyze --limit 50 — mine linked Wikidata claims + Wikipedia articles into profiles/timelines, stamping the *_analyzed_at completeness gates. --no-llm = Wikidata only. Requires make gatekeeper (+ ollama serve for the article analysis).
make cast-scorecast-manager score — recompute every character's completeness under the current constants (run after any metric change), persisting breakdowns and re-queuing deflated characters.
make location-managerlocation-manager run --batch 50 — extract places (descriptions, appreciations, events, data) from verified+mapped docs. location-manager-status prints counts.
make location-enrichlocation-manager enrich --limit 100 — link places to Wikidata + Wikipedia. Requires make gatekeeper.
make location-analyzelocation-manager analyze --limit 30 — mine linked places: GPS coordinates (P625), inception, architect, territory + the Wikipedia article (description, trivia). --no-llm = Wikidata only.
make location-scorelocation-manager score — bulk re-score all locations.
make cast-politicscast-manager politics --limit 200 — place characters on the political compass. Requires ollama serve.
make cast-clean / cast-clean-applycast-manager clean [--apply] — list (dry-run) or delete implausible characters (boilerplate, titles, months, orgs, function words). Deterministic, no LLM.
make curatedoc-curator run --batch 50 — assign utility flags to verified+mapped docs (Ag-9).
make curate-alldoc-curator run --all --batch 100 — curate every eligible doc.
make curate-statusCuration stats (curated docs, flags per slug).
make curate-recuratedoc-curator run --re-curate --batch 100 — re-curate already-processed docs (applies an improved prompt). Uses the LLM path.

Full cycles

TargetRuns
make pipelineOne full cycle: propositor → archivero → verificator → cleaner → mapper → cast-manager → cast-enrich (50) → cast-analyze (10) → cast-director → location-manager → location-enrich (50) → location-analyze (10) → doc-curator → export.
make pipeline-loopContinuous cycles (new missions when queue < 50; 30s delay). Same chain as make pipeline.
make pipeline-charactersCharacter-focused cycle (pipeline_runs.trigger = characters): propositor run --focus characters --entity-limit 30 mints entity missions ONLY — the least-complete characters (< 0.85) first — then archivero → verificator → cleaner → mapper → cast-manager → enrich (100) → analyze (30) → score → cast-director → export.
make drainarchivero → verificator → cleaner → mapper → cast-manager → cast-director → doc-curator → export (no new missions).
make drain-loopContinuous drain (30s delay).

Useful one-offs

uv run archivero export                         # write data/documents.json
uv run verificator status                       # verified / pending counts
uv run propositor run --retry-failed --no-llm --limit 100   # retry failed missions
uv run propositor run --entity-limit 0                      # gap missions only (skip character research)
uv run propositor run --focus characters --entity-limit 30  # entity missions only, thinnest characters first
uv run propositor run --focus cells                         # gap missions only (leaves the research queue queued)
