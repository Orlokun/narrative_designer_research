Archivero Ag-1 Real

Fetches documents for each mission through the Gatekeeper, extracts clean text, deduplicates by SHA-256, and writes the documents table.

Entry point: pipeline/archivero/__init__.py → main() · CLI: archivero run / status / export

Source routing

PathSourcesExtraction
JSON API (_JSON_SOURCES)archive.org, openalex, crossref, semantic_scholar, chronicling_america, wikipedia_esDedicated extractor in _JSON_EXTRACTORS.
Multi-step (special-cased in run_cycle)wikisource_es (search→parse), frus (sequential doc pages), marxists (index crawl), foia_chile (JSON search → PDF → pypdf OCR)Per-source helpers; foia_chile fetches binary PDFs through the Gatekeeper (_gatekeeper_fetch_binary, base64) and extracts the OCR text layer (_pdf_extract_text), keeping declassification metadata in a header (_foia_document_text).
HTMLbn_digital, web_serptrafilatura (80-char minimum applies here only).
  • _ERROR_PATTERNS rejects known bot-challenge / error pages before insertion.
  • foia_chile caps PDFs per query (_FOIA_MAX_DOCS_PER_QUERY = 5) — the API ignores its limit parameter and returns 20 results per page; each result costs a PDF download. Docs whose OCR layer yields < 80 chars are skipped.

Deduplication & identity

Documents are deduplicated by SHA-256 (UNIQUE INDEX idx_doc_sha256). doc_id = first 16 hex chars of the sha256. A duplicate still counts the mission as DONE.

Mission outcome logic

OutcomeCondition
DONE≥ 1 document found (new or duplicate).
PENDING (reset)All fetches failed at network level (timeout/5xx) — retried next cycle.
FAILEDSources reachable but no extractable content.

Coverage upsert

After each DONE mission, Archivero upserts the cell's score into the coverage table (_upsert_coverage_score): coverage_score = min(1.0, docs_found / 5). The Mapper later refines cell assignment per document.

Common invocations

make archivero                  # run --batch 50 --missions 200
uv run archivero status
uv run archivero export         # write data/documents.json (derived view)
