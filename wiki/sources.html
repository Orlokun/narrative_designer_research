How to add a source

  1. Gatekeeper: add a per-domain entry to research_engine/gatekeeper/rate_limits.yaml.
  2. Archivero: add a URL template to _SOURCE_URLS, a _SOURCE_KINDS entry, and either (a) a pure _x_extract(body) + membership in _JSON_SOURCES/_JSON_EXTRACTORS for JSON APIs, or (b) a multi-step special-case in run_cycle for crawl/2-step sources (see FRUS, Wikisource, Marxists).
  3. Propositor: add the source key to the relevant tier(s) in _SOURCES — otherwise no mission targets it.
  4. Tests: a pure extractor/parse test in tests/test_archivero.py (offline).

Key-gated APIs (manual keys) Planned

The connectors above are all keyless. A planned step adds sources whose APIs require a manually-supplied API key. The key is stored in .env and read via lib.config.settings (never hard-coded, never read from the env directly) — and the source is only enabled once its key is present, so a missing key skips the source rather than failing the run.

  1. Config: add the key field to lib/config.py settings; document it in .env.example.
  2. Gatekeeper: inject the key (header / query param) when fronting that domain's request.
  3. Enablement: the source registers in the Propositor tiers only when its key is configured.
