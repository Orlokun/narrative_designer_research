Admin Dashboard Real

A FastAPI app (admin.app:main, port 8080) that visualises the pipeline: the theme×genre coverage matrix (with its per-cell month strip), mission queue, per-agent stats and service health; the document reader lives on the Archivero page. Static pages live in admin/static/ (shared assets under the /static mount); routers in admin/routers/ (prefix /api). Every screen carries the same persistent navbar (nav.js).

▶ Admin convention — always hyperlink

The admin is always cross-linked. Names of entities are never dead text:

  • Every time a character appears, it links to /cast-manager?char=<character_id> — the page opens with that character selected.
  • Every time a document is mentioned, it links to /archivero?doc=<doc_id> — the reader lands on that document (filters cleared, prev/next intact via its carousel position). Implemented in: Archivero recent table, Mapper recent mappings, Cast Manager mention list and timeline source marks (¶).
  • The text reader lives on the Archivero page (archivero.html); GET /api/documents/by-id/{doc_id} backs the deep link (doc + carousel position, reachable even if unverified).

Routers (admin/routers/)

RouterExposes
health.py/health/services, /health/gatekeeper/status, /health/gatekeeper/log — RE service status & recent fetch log.
heatmap.pyCoverage-matrix endpoints over the 16×13×48 cube: /api/heatmap/genres (theme×genre projection with plausibility priors, unclassified counts and a plausibility-weighted coverage % — the dashboard's main grid, implausible empty cells dashed), /api/heatmap/genres/months (the 48-month strip for one clicked theme×genre cell, critical months marked; genre 0 = unclassified bucket), and /api/heatmap (legacy theme×month projection, kept for API consumers).
database.py/database — table row counts, DB file size, 10 recent documents, source-kind distribution.
pipeline.py/pipeline — mission-queue counts by status + Archivero document stats.
documents.pyPaginated document browser (carousel) + /documents/by-id/{doc_id} (one doc + its position in the unfiltered carousel order — backs every "doc mentioned" deep link), category encode/decode, verification-status filters.
agents.py/agents/{propositor,archivero,verificator,mapper} — per-agent detail. The mapper endpoint reports mapped/pending/context counts, genre + category distributions and recent mappings. The verificator endpoint reports the acceptance threshold by reading the Verificator's own constant (never hardcoded), so the UI always reflects the real pipeline value.
cast.py/cast/characters (searchable list), /cast/characters/{id} (bio, life-line, timeline, documents), /cast/characters/{id}/relations (a character's relations, both directions) and /cast/graph (the whole relation network — edges carry kind, confidence, directedness, description and provenance) — back the /cast-manager and /cast-director pages.
locations.py/locations (searchable list + summary: total, complete, with_coordinates — every row carries latitude/longitude so the page plots the map from one request) and /locations/{id} (profile, parsed completeness_detail, linked character via JOIN, per-kind facts, mentioning documents) — back the /locations page.
performance.py/performance — recent pipeline runs, each with its per-stage timing breakdown; /performance/{run_id} — one run's stages in detail. Reads pipeline_runs + pipeline_run_stages.

Static pages (admin/static/)

FilePurpose
nav.jsShared persistent navbar injected into every screen (served from the /static mount). The page list lives in one PAGES array — adding a future agent page = one entry here + its route in admin/app.py. The bar scrolls horizontally, so it scales to many agents: a visible scrollbar, mouse-wheel horizontal scrolling, and the active page auto-centred on load. Right-alignment comes from margin-left:auto on the first item — never justify-content:flex-end, which with overflow clips the first links unreachably.
index.htmlMain dashboard — the theme×genre matrix is the only grid; clicking a cell unfolds its 48-month strip below (close with ✕). Plus mission queue, DB stats and service health (the dark/amber "Ops Room" UI this wiki's palette nods to).
propositor.htmlMission-queue detail.
mapper.htmlMapper page — mapping state cards (mapped / pending / context / % with genre), genre + category distribution bars, recent mappings table.
cast-manager.htmlCast Manager page (per the roadmap design): left sidebar with searchable character list + completeness bars, topped by a calibration strip (/api/cast/stats: complete count vs the 0.85 threshold, 10-bucket score histogram, and how many characters each hard gate caps); central detail shows the strict metric's per-component breakdown bars + active gates from completeness_detail; central detail with biography, an SVG life-line chart (birth→death, 1970–1973 highlighted, lollipop per fact), the dated timeline list (statements render as «quotes» with their speech act; rumors dimmed, marked ≈ and attributed "— según reported_by"), a Relaciones section (Cast Director relations, each linking to the other character + provenance docs) and the documents mentioning the character.
locations.htmlLocations page (/locations, "Lugares" in the navbar): left sidebar with searchable location list + completeness bars (📍 marks located places, ⌕ queued research); an SVG coordinate map — self-contained, no external tiles — that auto-fits the plotted Wikidata coordinates (equirectangular with cos-latitude correction, adaptive graticule, dots coloured by kind and sized by mentions; click a dot to open the place); detail with description, external links, coords, the linked character (hyperlinks to /cast-manager?char=… per the always-hyperlink convention), an image gallery (Commons-hosted P18 + article lead image, lazy-loaded and hidden on load failure, each thumb linking to its Commons File: page for licence/attribution), per-kind facts (appreciations render as «quotes» attributed "— según reported_by") and the mentioning documents (reader links). Deep-linkable via ?loc=….
cast-director.htmlCast Director page — a force-directed relationship network graph (nodes sized by degree; edges coloured by kind, width + opacity by confidence). Directed relations (superior/mentor) draw an arrowhead; clicking an edge opens a detail panel (both characters linked, description, confidence, provenance document links); kind chips and a confidence-threshold slider filter what is shown; click a node to open its character; drag to rearrange. No JS dependencies.
archivero.htmlDocument fetch statistics — hosts the document reader (lector de documentos: paginated viewer with category/month/verified filters, moved here from the dashboard; a "doc mentioned" link opens it here with that document loaded).
verificator.htmlScoring / approval dashboard.
performance.htmlPer-run timing. A left list of pipeline runs (most-recent first); selecting one shows that run's wall-clock duration, summed stage time and a per-stage timing breakdown with each stage's counts. Served at /performance.
