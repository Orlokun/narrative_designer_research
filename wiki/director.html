Director Real

The runtime orchestrator for the game simulation. A custom, dependency-free graph: one mutable WorldState flows through a sequence of registered async nodes. No LangGraph / CrewAI — an explicit loop with hooks for transitions, errors and checkpoints.

Location: runtime/director/orchestrator.py + runtime/director/world_state.py

Role in the system

The Director belongs to the runtime layer — the eventual game loop, distinct from the research pipeline that harvests documents. It coordinates the runtime agents (event generator, NPC pool, ledger, logger, registrador), most of which are still Stub.

Design notes

  • WorldState is the single mutable object passed between nodes.
  • Nodes are registered async callables; the orchestrator runs them in order with hooks for transitions, error handling and checkpointing.
  • Deliberately framework-free, to keep the loop explicit and debuggable.
⚠ Runtime layer is early

The Director exists, but the runtime agents it orchestrates and the game-facing pieces (scenarios, NPC dialogue, metrics) are largely unbuilt or part of the lost work. Tracked on the Roadmap.
